# 法律来源、版本与效力控制

## 何时读取

在以下任务中读取本文件：完整法律解读、多文件合规研究、外文法律翻译、修法比较、法律状态核验、法律文件台账或需要对结论进行正式溯源的交付。

如果用户只针对已经提供且状态明确的文本询问一个局部问题，可以只执行必要的来源核对，不必扩展为完整文件台账。

## 控制原则

- 以官方原始文本为控制版本；译文、检索副本和内部分析只作为辅助版本。
- 先确认文件身份、效力、版本、适用时间和完整性，再解释实体规则。
- 结论必须与其直接依据对应，不得用新闻稿、二手摘要或内部表格替代正式文本。
- 无法取得官方全文、附件或最新修订时，明确披露证据缺口及其对结论的影响。

## 官方来源优先级

根据法域实际制度选择控制来源，通常依次核验：

1. 官方公报、立法机关或法规数据库公布的正式文本；
2. 政府、主管机关或法院发布的正式文件；
3. 文件附件、附表、实施决定、授权法案或配套法令；
4. 正式指南、问答、解释文件和技术标准；
5. 可验证的权威译文或数据库副本；
6. 新闻稿、专业文章和其他二手材料。

后位来源可以帮助检索和理解，但不能在前位正式来源可得时取代前位来源。网页标题、搜索摘要、登录页、下载失败页或仅含元数据的页面不构成已读取正文的证明。

## 文件台账

至少记录：

| 字段 | 核验内容 |
|---|---|
| 正式名称及编号 | 名称、编号、法域和发布机构 |
| 文件类型 | 法律、法规、实施文件、决定、草案、指南、标准等 |
| 关键日期 | 通过、签署、公布、发布、生效和开始适用日期 |
| 法律状态 | 现行、待适用、已废止、部分失效、草案或非约束性 |
| 官方来源 | 官方链接、查询日期、下载文件和公报信息 |
| 语言与版本 | 控制语言、译文、修订版本和历史版本 |
| 完整性 | 正文、定义、附件、附表、脚注及修订标记是否齐全 |
| 文件关系 | 上位法、实施文件、授权依据、附件、指南及替代关系 |

## 法律状态结论

分别核对文件是否正式通过、是否公布、是否已经生效、是否开始适用、是否存在过渡期，以及是否仍可能修订。输出结论时使用清晰状态，例如：

- 现行且已经适用；
- 已生效但尚未开始适用；
- 正式公布但处于过渡期；
- 非约束性但用于解释现行义务；
- 尚在审议或征求意见；
- 已废止、被替代或仅对存量事项继续适用。

不得把“发布”“通过”“公布”“生效”和“开始适用”混为同一日期。草案、审议文本和新闻说明不得写成现行强制义务。

## 全文与附件完整性

- 阅读正文、序言、定义、例外、过渡条款、附件、附表、脚注和交叉引用。
- 风险清单、禁止清单、产品清单、处罚表或技术附件必须作为正文的一部分核验。
- 扫描件先进行OCR，再抽样核对条款编号、否定词、金额、日期、表格和专有名词。
- 对长文件建立覆盖记录，确保章节、条款和附件连续完整。
- 引用交叉条款时回读被引用条款，不依据单一条文孤立下结论。

## 原文、译文与分析稿

将文件分为三层：

1. **原始控制版本：**官方语言的正式文本及附件；
2. **工作辅助版本：**可检索文本、OCR结果或完整译文；
3. **分析成果：**法律意见、规则底表、业务指引和自查工具。

翻译应完整保留条款编号、定义、附件、表格、脚注和限定语，不得删减或混入法律意见。疑难术语保留原文，并建立术语一致性记录。引用译文作出结论时，应能够回查对应原文位置。

## 多文件关系

当一个监管制度由多份文件共同形成时，建立“制度—文件—条款”关系：

- 上位法规定基本定义、角色、分类和授权；
- 实施文件细化条件、程序、期限和材料；
- 主管机关决定或附件列出具体对象、清单或技术范围；
- 指南、问答或标准解释实践，但需标记其约束力；
- 行业法可能补充、替代或避免重复履行一般AI法律要求。

汇总规则时说明每份文件分别提供了什么，不把实施细节错误归入上位法，也不把指南内容写成法律正文。

## 修订与版本控制

- 确认当前控制版本及截至日期；
- 保留旧版本并制作新旧条文或清单差异；
- 识别新增、删除、替换、延后适用和过渡安排；
- 评估修订对既有分类、义务、业务结论和交付文件的影响；
- 未正式通过的修订只作为趋势或预备事项；
- 对可能变化的监管状态，在交付前重新核验官方来源。

## 证据缺口

以下情况不得表述为已经核验全文：

- 只能访问摘要、新闻稿或登录页；
- 附件、附表或脚注缺失；
- 下载文件损坏、内容为空或无法确认版本；
- 只有非官方译文且无法回查原文；
- 无法确认修订是否最终通过或何时适用。

记录缺失材料、已完成的替代核验、当前能够支持的有限结论，以及取得材料后需要重新检查的事项。

## 完成标准

完成来源和状态控制后，应能够明确回答：

1. 实际读取了哪些文件和哪些版本；
2. 哪一份是控制文本；
3. 文件是否正式、有效并已经适用；
4. 正文和附件是否完整；
5. 多份文件之间如何共同形成监管规则；
6. 哪些结论仍受来源或版本缺口限制。
